# Contribuir a Crowther

Crowther v1.0.0 está publicado inicialmente en español. Para informar de un
fallo, abre una incidencia e incluye el sistema operativo, navegador, pasos
para reproducirlo y el resultado esperado. No adjuntes proyectos o recursos
privados sin revisarlos antes.

Antes de proponer cambios en el código:

1. Conserva las licencias y atribuciones existentes, incluidos los avisos de
   `vendor/` y `RUNTIME-LICENSE-EXCEPTION.txt`.
2. Ejecuta `./scripts/Validar-Proyecto.ps1` en PowerShell y describe qué
   pruebas pudiste completar.
3. Mantén la aplicación ligera y funcional sin dependencias de npm ni CDNs
   obligatorias.
